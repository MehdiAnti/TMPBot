# TMPBot

A simple Telegram bot that provides real-time **TruckersMP** information directly in Telegram.

## Features

- Server status and player counts
- TruckersMP game time
- Current TruckersMP version
- TruckersMP events
- TruckersMP rules

## API

Uses the official **TruckersMP Web API**:

https://docs.truckersmp.com/web-api/

## Tech Stack

- Python
- Flask
- Telegram Bot API
- TruckersMP Web API
- Render

## Deployment

TMPBot runs as a Flask web service and is deployed on **Render**.

### Environment Variables

BOT_TOKEN
WEBHOOK_URL
